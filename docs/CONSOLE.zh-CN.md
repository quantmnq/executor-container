# 安装控制台（预览版）

[English](CONSOLE.md) | 简体中文

安装控制台是在浏览器中打开的私密页面，完成与 `./follow-stack setup` 相同的步骤：
Docker 与开机运行、经过验证的执行器镜像、账户与仓位大小、Gateway 登录、手机批准、
就绪检查以及明确的启动。它还可以查看状态和日志、停止跟单，并在之后更改仓位大小和
Discord 通知。控制台运行的代码与终端
向导相同，因此每项检查、需要输入的确认短语以及保存的文件都完全一致。

使用前需要在 Ubuntu 24.04 ARM64 上准备好合并容器安装包（`follow-stack-…`），并能
通过 SSH 连接到 VM。Oracle 注册和 IBKR 账户准备仍按 [SETUP.zh-CN.md](SETUP.zh-CN.md)
和 [IBKR_ACCOUNT_SETUP.zh-CN.md](IBKR_ACCOUNT_SETUP.zh-CN.md) 进行。

## 打开控制台

在你自己的电脑上运行一条命令。它会连接 VM，通过 SSH 转发控制台和恢复桌面的端口，并
启动控制台：

```bash
ssh -i ./auto-quant.key -t -L 8765:127.0.0.1:8765 -L 5901:127.0.0.1:5901 ubuntu@YOUR_OCI_PUBLIC_IP './follow-stack-VERSION-ubuntu24.04-arm64-cp312/follow-stack console'
```

请把密钥路径、IP 地址和 `VERSION` 换成你自己的。命令会打印一个私密链接，例如
`http://127.0.0.1:8765/#token=…`。在同一台电脑的浏览器中打开它。使用页面期间请保持
SSH 窗口打开。

选择 **继续安装**。控制台会检查 VM，并停在第一个需要你处理的步骤。按提示填写每个
表单。页面顶部可选择 **中文** 或 **English**。

## 保持不变的规则

- 安装本身不会开始交易。只有就绪检查通过后才会出现 **开始跟单**，并且必须准确输入
  显示的短语，例如 `START PAPER BALANCE 0.5`。
- 真实账户模式需要与终端向导相同的确认输入。
- 只有在你同意后，才会使用 sudo 安装 Docker 或启用用户服务常驻。Docker 更改之后需要
  重启一次 VM，控制台会提供按钮。重启后再次运行同一条 SSH 命令，并打开新的链接。
- **停止跟单** 不会平仓，也不会撤销券商订单。除非你自行处理持仓，否则只在空仓时停止。

## 之后更改设置

账户保存后会出现 **设置** 卡片。更改仓位大小和 Discord 设置需要执行器处于停止状态，
因此跟单运行期间该卡片只显示高级恢复。

- **更改仓位大小**：选择按余额计算并填写杠杆比例，或选择固定数量的 MNQ 或 NQ。填写
  NQ 大致价格后，可按你的 IBKR NetLiquidation 和示例权重预览仓位。账户必须空仓、未暂停
  且没有未完成订单，Gateway 也必须已登录。如果更改被拒绝，原设置会保留。新仓位在下次
  启动时生效。
- **Discord 通知（可选）**：阅读共享内容说明，输入 `LINK` 并选择 **获取配对码**。在服务
  提供方的 Auto Quant Discord 服务器中，把显示的 `/link code:…` 命令发送给 AQ Bot。收到
  测试私信后，选择 **启用通知**。详见 [DISCORD.zh-CN.md](DISCORD.zh-CN.md)。
- **高级恢复**：**执行器状态** 会显示执行器是否已暂停。只有在检查账户后，才输入
  `RESUME` 请求暂停恢复。运行中的执行器随后会接管券商当前持仓，并按最新目标调整，可能
  会平仓。

更改仓位大小或 Discord 设置后，请在开始前重新进行就绪检查。

## 隐私

- 控制台只在 VM 的 127.0.0.1 上监听，你通过 SSH 连接访问它，无需修改 OCI 安全列表
  或防火墙。
- 每个打印出的链接只能使用一次，使用后成为私密的浏览器会话。不要分享该链接。
- 个人令牌、IBKR 用户名和密码以及恢复桌面密码只输入到控制台页面中。它们会保存到与
  终端向导相同的私密文件中，不会再次显示，也不会写入日志。
- AI 助手可以启动控制台并查看进度，但绝不能代填凭据字段，也不能在聊天中接收这些信息。

## 关闭与重新打开

在 SSH 窗口按 Ctrl+C 或直接关闭 SSH 窗口即可关闭控制台；闲置 30 分钟后也会自动关闭。
Gateway 和执行器保持当前状态。再次运行 SSH 命令即可重新打开，安装会从已保存的步骤继续。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 页面无法打开 | 连接时没有使用 `-L 8765:127.0.0.1:8765`。关闭 SSH 窗口，改用上面的命令 |
| 显示“此页面未连接” | 该链接已经用过。在 SSH 窗口按 Ctrl+C，重新运行命令并打开新链接 |
| 8765 端口被占用 | 已有另一个控制台在运行，或本机程序占用了该端口。在 `console` 后加 `--port 8766`，并改为转发 `8766` |
| Gateway 弹窗需要处理 | 用 VNC 查看器打开 `localhost:5901`（TigerVNC：`localhost::5901`），输入恢复桌面密码 |
| 某一步失败 | 阅读表单下方的输出，按提示处理后选择 **继续安装**。已保存的设置会保留 |

终端向导随时可用：`./follow-stack setup`。维护与恢复请参阅
[CONTAINER_SETUP.zh-CN.md](CONTAINER_SETUP.zh-CN.md)。
